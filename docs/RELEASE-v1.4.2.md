# v1.4.2 · 登录成功提示校准与登录页面板恢复

> 本版修复两个连续使用场景中的误判和不便：使用官服账号进入游戏时，不再把面板中残留的渠道服选择当成实际登录渠道；进入游戏后面板自动隐藏后，刷新或回退到官服登录页会重新显示面板入口。

## 本版更新

### 登录成功提示与渠道校准

- 进入游戏页后显示居中的“登录成功”提示，提示显示片刻后自动隐藏整个登录面板。
- 渠道优先按当前游戏 URL 的 `channel_id` 判定，其次才读取游戏运行时账号字段；不再读取面板中上次选择的渠道。
- 路由与运行时证据冲突、缺少证据或无法唯一确认时，显示中性的“已使用账号进入游戏。”，不猜测渠道。
- 官服只匹配明确的官服渠道号，不再把应用宝、WeGame 等合作渠道误判为官服。
- 覆盖“先使用 Vivo 渠道服、后在面板仍选中 Vivo 时改用官服登录”的场景：以游戏页实际渠道证据为准。

### 刷新与回退后的面板恢复

- 官服登录页路由统一识别 `/login/x/index`、`/login/index.html`、`/login/10th_client/index.html` 及其无扩展名形式。
- 刷新或重新进入登录页时清除面板自动隐藏标记，并恢复面板可见；即使上一页的登录成功提示已经隐藏整个面板，也能重新获得入口。
- 监听 BFCache `pageshow` 与浏览器 `popstate`，回退或前进到登录页时不依赖脚本重新初始化。
- “主登录页自动展开”仍只控制登录内容是否展开，不会阻止面板宿主重新显示。

## 验证

- `npm test`：35 项回归测试全部通过。
- 新增断言覆盖 `/login/x/index`、`/login/index.html`、隐藏标记清除、BFCache 恢复和浏览器回退。
- 正式版、本地测试版与独立引擎均通过 `node --check`；主脚本内嵌引擎与 `_direct_engine.js` 保持同步。

## 安装或升级

- 下载 [`sanguosha-channel-login.user.js`](https://github.com/softbad123/sanguosha-channel-login/releases/latest/download/sanguosha-channel-login.user.js)，在 Tampermonkey 中覆盖安装。
- 安装后刷新登录页，页脚应显示 `v1.4.2 · 9 个渠道`。
- 不要同时启用旧版统一登录器或其他会向同一页面注入登录面板的脚本。

## 已知限制

- 本版只修复页面识别、面板恢复和提示文案，不改变官方授权、实名、支付或风控流程。
- 最终能否登录仍由渠道服务器、游卡服务器、账号状态和游戏服务器共同决定。
